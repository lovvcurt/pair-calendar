# Календарь как Telegram Mini App

Mini App открывает существующий сайт календаря прямо внутри Telegram. Это тот же React-интерфейс, тот же проект на GitHub Pages и та же база Supabase. Отдельную копию календаря создавать не нужно. PWA на телефоне продолжит работать отдельно.

## Что нужно заранее

- Сайт уже опубликован на GitHub Pages и открывается по HTTPS.
- У вас есть аккаунт Telegram.
- Вы знаете данные для входа в существующий аккаунт приложения.

## 1. Скопируйте адрес сайта

Откройте репозиторий GitHub → **Settings → Pages** и скопируйте адрес сайта. Он похож на `https://ВАШ_ЛОГИН.github.io/pair-calendar/`. Откройте ссылку в обычном браузере и проверьте, что календарь загружается.

## 2. Создайте бота через BotFather

1. В Telegram найдите официальный **@BotFather** и откройте чат.
2. Отправьте `/newbot` и следуйте вопросам: задайте имя бота, затем уникальный username, который заканчивается на `bot`.
3. Запишите username бота, чтобы потом открыть его. BotFather покажет **HTTP API token**. Для запуска Mini App по кнопке этот токен не нужен. Не отправляйте его никому и не вставляйте в сайт, GitHub, SQL или этот чат.

## 3. Назначьте сайт Mini App

1. В чате с @BotFather отправьте `/mybots`.
2. Выберите созданного бота, затем **Bot Settings → Configure Mini App → Enable Mini App**. Названия могут немного меняться в зависимости от версии Telegram.
3. Вставьте HTTPS-адрес сайта из первого шага. При желании задайте название и картинку Mini App.
4. Чтобы добавить кнопку внизу чата с ботом, отправьте @BotFather `/setmenubutton`, выберите бота, укажите надпись, например **Открыть календарь**, и вставьте тот же адрес сайта.

Можно также настроить **Main Mini App**: тогда в профиле бота появляется кнопка запуска приложения. В BotFather найдите настройки Main Mini App у созданного бота и укажите там этот же HTTPS-адрес.

Официальная справка: [Telegram Mini Apps](https://core.telegram.org/bots/webapps). Telegram требует проверять `initData` на сервере, прежде чем использовать его как подтверждение личности.

## 4. Откройте календарь

1. Найдите username бота, откройте личный чат и нажмите **Start**.
2. Нажмите кнопку Mini App или **Открыть календарь**.
3. Войдите по почте и паролю от уже существующего аккаунта календаря.
4. Партнёр открывает того же бота, но входит под своим отдельным аккаунтом.

Войти сначала в обычном браузере удобно, если у вас ещё нет аккаунта: подтверждение регистрации по почте может открыть внешний браузер. После подтверждения просто войдите в Mini App по почте и паролю.

## Что уже делает приложение в Telegram

При открытии Telegram-версия сообщает Telegram, что страница готова, раскрывает окно и подстраивает минимальную высоту интерфейса под окно Mini App. Сам календарь загружается с GitHub Pages, а данные по-прежнему защищает Supabase и его правила доступа.

Сейчас вход выполняется через Supabase. Telegram-аккаунт сам по себе не даёт доступ к календарю, и приложение не использует непроверенные данные пользователя из Telegram. Автоматический вход через Telegram потребовал бы отдельной серверной проверки и безопасной привязки аккаунтов.

## Ограничения

- Mini App требует интернет для входа, синхронизации и сохранения данных.
- Запуск Mini App не даёт сайту прямого доступа к календарю Android. Для переноса событий остаётся импорт/экспорт `.ics`.
- Уведомления из установленной PWA и сообщения Telegram-бота — разные функции. Чтобы бот отправлял личные сообщения с напоминаниями при закрытом приложении, каждый участник должен начать чат с ботом, а проекту потребуется отдельная защищённая серверная отправка и привязка Telegram к аккаунту.
- В этом проекте Mini App не настроен на вход Telegram без пароля и не отправляет напоминания в чат бота.
